# Voice-over — recording checklist

> Auto-generated by `pnpm voice-over:todo` — **do not edit by hand** (re-run to refresh).

**How to record a line.** Say the text below, save it as an `.ogg` named *exactly* after
the `LINE_ID`, and drop it at the path shown. Re-run the command and the box ticks itself.
Anything in `public/speech/de/` flat works too — LINE_IDs are unique — but the
per-speaker folder keeps one voice in one place.

A LINE_ID is `<group>-<hash of the German text>`. It does **not** move when a line is
inserted above it, and it *does* change when the line itself is rewritten — at which point
the old recording is of a sentence the game no longer contains, and the box un-ticks itself
on purpose. See `src/voice/lines.ts`.

Locale: run `VO_LOCALE=en pnpm voice-over:todo` for the English list. The TTS placeholder
voice named per section comes from `src/voice/voices.ts` and is what plays until a
real recording lands on top of it.
